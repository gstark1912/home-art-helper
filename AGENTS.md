# Entrada para agentes

Antes de trabajar, leer todos los archivos Markdown de `.kiro/steering/`, luego `tasks/README.md` y la tarea asignada.

Las reglas de programación y colaboración se mantienen exclusivamente en `.kiro/steering/`. Actualizarlas allí; este archivo sólo sirve para descubrirlas. No iniciar trabajo de implementación sin una tarea con alcance y responsable definidos.

Ante «continuá con la próxima tarea», aplicar `.kiro/steering/task-selection.md`: seleccionar y reservar automáticamente una tarea elegible; si no hay ninguna, informar los bloqueos y terminar.
